Alex 2.0

Voice-enabled AI assistant and investor presentation concept

Project objective

Explore a native iPhone assistant that combines conversational AI, speech input and output, an animated avatar and a dedicated investor presentation mode for RepairLens and OhmLoom.

iOS interface

SwiftUI, animated vector avatar, Apple Speech dictation, AVSpeechSynthesizer and local conversation history.

Backend architecture

Node.js chat server with server-side API credentials and authenticated requests. HTTPS deployment required.

Build workflow

XcodeGen and GitHub Actions cloud build configuration for an unsigned IPA.

System design

Speech or text input → SwiftUI app → authenticated HTTPS chat backend → AI response → speech synthesis and avatar animation.

Prototype status

Source-code demonstration, not a production-ready app. Current build, signing, backend deployment and LiveContainer compatibility are not verified. Avatar animation is speech-state based, not phoneme-accurate lip sync. Fully hands-free conversation and production security remain future work.
